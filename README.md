#  Mobile Store Frontend

This is the **frontend** of the **Mobile Store** web application, built using **React.js** and **Create React App**. It connects with the **Go (Gin) backend** to display mobile products, handle user authentication, and provide role-based access (Admin/Customer).

### Loom video link
https://www.loom.com/share/e6989aae5b1542bf8742020489ad8430?sid=d63aebe2-afdf-4caa-b57d-6c29da6bc19c 

### Features
Admin Dashboard: Admins can manage products (create, update, delete).

User Authentication: Registration, login, and JWT-based session management.

Product Catalog: Customers can view and browse mobile products.

Responsive UI: Works well on both mobile and desktop devices.

##  Getting Started

### Clone the repo

```bash
git clone https://github.com/JayeshJadhav1107/mobile_store_frontend.git
cd mobile_store_frontend
```

### Install dependencies

```bash
npm install
```

### Run the app
```bash
npm start
```
